Hàng đợi nhiệm vụ giao đồ

Robot chạy lần lượt từng điểm; tới nơi thì chờ bạn xác nhận đã giao rồi mới đi tiếp.

Hệ thống

Bật/tắt các thành phần ROS2. Bình thường bạn không cần vào đây: chọn "Quét bản đồ" hoặc "Kích hoạt" bản đồ là web tự bật đúng stack.

Điều hướng (Nav2)

Áp dụng ở lần khởi động Nav2 kế tiếp (vào lại chế độ Điều hướng để đổi).
